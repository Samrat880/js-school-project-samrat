# Car Industry Timeline

This is a simple front-end project for the JS School program that displays a timeline of key events in the history of the automotive industry. The project is built using pure, semantic HTML and is structured to be clear and easy to understand.

## Features

* **Semantic HTML:** The project uses modern HTML5 tags like `<header>`, `<main>`, `<footer>`, `<section>`, and `<article>` for a well-structured and accessible layout.
* **Timeline Layout:** Events are organized in a `<table>` to present the information in clean, easy-to-read rows.
* **Historical Data:** Includes major milestones from the first steam-powered vehicle in 1769 to the rise of electric and autonomous cars.
* **Local Images:** Demonstrates the use of local images within the project structure for specific timeline events.

No special setup is required. To view the project, simply:

1.  Clone or download the repository to your local machine.
2.  Open the `index.html` file directly in any modern web browser (like Chrome, Firefox, or Edge).
